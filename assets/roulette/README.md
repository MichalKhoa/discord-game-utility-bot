# Russian Roulette GIF Assets

Place your custom animated GIFs in this directory. The bot will automatically detect and display them in embeds if present:

- `spin.gif` — Displayed during the 1.2s suspense / cylinder spin animation.
- `boom.gif` — Displayed when a player hits the live round (`💥 BANG!`).
- `safe.gif` — Displayed when an empty chamber clicks (`💨 *Click!*`).

### Recommended GIF Sources:
1. **Giphy / Tenor**: Search "revolver spin", "russian roulette", "gunshot retro pixel", "empty click".
2. **EZGIF (ezgif.com)**: Crop, resize, and optimize any video clip into an efficient small GIF (<2MB).
3. **Pixel Art / Itch.io**: Search free 2D game asset packs for revolver animations.
